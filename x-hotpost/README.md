# 热帖 · 热点审核发布（无 X API）

自动跟踪热点 → 生成发帖草稿 → **你审核通过后**再发布。后台定时跑，不用一直盯着。

**不使用 X API。** 真发帖时用本机 Chromium 已登录会话，在网页端代你点「发帖」。

## 能做什么

1. **跟踪热点**：按赛道拉取公开 Google News RSS（演示模式还有内置样本）
2. **自动写草稿**：本地模板，或可选 OpenAI 兼容接口
3. **人工审核**：改文案 / 通过 / 拒绝；通过前不会发帖
4. **浏览器发布**：审核通过后，用本机已登录的 X 网页会话发帖
5. **变现钩子**：可配置联盟链接与 CTA 模板，写进草稿结尾

## 快速开始

```bash
cd x-hotpost
npm install
npx playwright install chromium
npm run dev
```

- 前端：http://127.0.0.1:5173
- API：http://127.0.0.1:8788

打开后点「立即跑一轮」，即可看到热点与待审草稿。默认是**演示模式**（只本地记发布，不打开浏览器）。

## 接真 X 账号（浏览器登录，无 API）

1. 在本机项目目录执行：

```bash
npm run x:login
```

2. 弹出的 Chromium 里登录你的 X 账号，进入首页后回到终端按 **Enter**
3. 在「设置」里**关闭演示模式**并保存
4. 审核通过一条草稿 → 后台会打开该会话自动发帖

会话保存在 `data/browser-profile/`（已 gitignore）。换号或失效时重新跑 `npm run x:login`。

> 网页结构若变更，自动点击可能失败；可在设置里关掉「无头模式」观察操作过程。请遵守 X 用户规则，控制频率，只发你审核过的内容。

## 变现怎么用

- 选准赛道（科技、财经、自媒体、自定义关键词）
- 在设置里填 **产品 / 联盟 / 社群** 链接与 CTA
- 每条热点给出你的判断，而不是纯搬运标题
- 保持审核：垃圾内容会伤账号，也伤变现

## 目录

```
x-hotpost/

```
